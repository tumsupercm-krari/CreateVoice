# CreateVoice — Voice Changer (Level 1)

หน้าเว็บไฟล์เดียวสำหรับแปลงเสียงพูดของคุณเป็นเสียงผู้หญิง เด็ก ผู้ชายทุ้ม คนแก่ ฯลฯ
ประมวลผลทั้งหมดในเบราว์เซอร์ **ไม่มีการอัปโหลดไฟล์ไปที่ใด** ไม่ต้องติดตั้งอะไร

## วิธีใช้

1. ดาวน์โหลด `index.html` แล้วดับเบิลคลิกเปิดใน Chrome / Edge
   (หรือเปิดผ่าน GitHub Pages ถ้าเปิดใช้งานไว้ — การอัดเสียงด้วยไมค์ต้องใช้ HTTPS หรือ `localhost`
   ถ้าเปิดแบบไฟล์ตรง ๆ แล้วไมค์ไม่ทำงาน ให้ใช้ปุ่มอัปโหลดไฟล์แทน หรือรัน `python -m http.server` แล้วเปิด `http://localhost:8000`)
2. **ใส่เสียงต้นฉบับ**: กด "● อัดเสียง" (กดอีกครั้งเพื่อหยุด) หรือเลือกไฟล์เสียง (wav, mp3, m4a, ogg)
3. **เลือกเสียง**: กดพรีเซ็ต แล้วปรับสไลเดอร์เพิ่มได้
4. กด **แปลงเสียง** เพื่อฟังผลลัพธ์ แล้วกด **ดาวน์โหลด WAV** เพื่อบันทึก

## พรีเซ็ตและสไลเดอร์

| พรีเซ็ต | Pitch | ความเร็ว | เสียงสั่น | เสียงเบาแกว่ง | ทุ้ม/แหลม |
|---|---|---|---|---|---|
| ต้นฉบับ | 0 | 1.00 | 0 | 0 | 0 |
| ผู้หญิง | +4 st | 1.00 | 0 | 0 | +3 dB |
| เด็ก | +7 st | 1.05 | 0 | 0 | +4 dB |
| ผู้ชายทุ้ม | −4 st | 0.97 | 0 | 0 | −4 dB |
| คนแก่ | −1 st | 0.88 | 55% | 25% | −5 dB |
| คุณยาย | +2.5 st | 0.85 | 60% | 30% | −2 dB |

- **Pitch (semitone)**: ยกหรือลดระดับเสียง 12 st = 1 octave
- **ความเร็ว**: เปลี่ยนความเร็วพูดโดยไม่เปลี่ยน pitch
- **เสียงสั่น**: เสียงสั่นพริ้วแบบคนสูงอายุ (vibrato)
- **เสียงเบาแกว่ง**: ความดังขึ้นลงช้า ๆ (tremolo)
- **ทุ้ม/แหลม**: ปรับสมดุลความถี่ เพื่อให้โทนเสียงดูแหลมหรือทุ้มขึ้น

## เคล็ดลับให้เสียงออกมาดี

- อัดในห้องเงียบ ห่างไมค์ประมาณ 1 ฝ่ามือ พูดชัด ๆ ไม่ต้องเร็ว
- ปรับ Pitch ไม่เกิน ±6 st จะฟังเป็นธรรมชาติกว่า ยิ่งปรับมากเสียงยิ่งฟังเหมือนเสียงแปลง
- เสียงคนแก่: พูดช้าและเบาลงตอนอัด แล้วค่อยใช้พรีเซ็ต จะได้อารมณ์ที่เนียนกว่า
- ถ้าเสียงมีเสียงก้องหรือแตก ลองอัดใหม่ให้เบาลง หรือลดสไลเดอร์ "ทุ้ม/แหลม"

## ข้อจำกัด

เป็นการแปลงด้วยสัญญาณเสียงพื้นฐาน (เลื่อน pitch ด้วย resample + SOLA time-stretch, vibrato/tremolo และ EQ)
**ไม่ใช่ AI** จึงไม่ได้เปลี่ยน formant จริง เสียงผู้หญิงหรือเด็กจะยังฟังออกว่าเป็นเสียงแปลง
ผลลัพธ์เป็นโมโน และใช้ได้ดีกับเสียงพูดมากกว่าเพลง
ถ้าต้องการคุณภาพสูงขึ้น ขั้นต่อไปคือใช้โมเดล AI เช่น RVC หรือ API อย่าง ElevenLabs เป็น backend

## การทำงานภายใน (สำหรับนักพัฒนา)

ทั้งหมดอยู่ใน `index.html` (ไม่มี dependency):

1. `resample()` อ่านเสียงด้วยอัตราเร็วที่ต่างออกไป ทำให้ pitch เปลี่ยน (ความยาวเปลี่ยนด้วย)
2. `stretch()` ยืด/หดเวลาด้วย SOLA เพื่อคืนความยาวเดิม (pitch จึงเปลี่ยนโดยความยาวคงเดิม)
3. `OfflineAudioContext` ใส่เอฟเฟกต์: vibrato (delay ที่แกว่งด้วย LFO), tremolo, high/low shelf
4. normalize แล้ว `encodeWav()` เป็น WAV 16-bit

## ทดสอบแล้ว

ทดสอบด้วย Chromium headless กับไฟล์เสียงสังเคราะห์ 2 วินาที: พรีเซ็ตผู้หญิง คนแก่ และเด็กแปลงสำเร็จ
ความยาวและ pitch เปลี่ยนตามที่คาด (คนแก่ยาวขึ้นตามความเร็ว 0.88x) ยังไม่ได้ทดสอบกับเสียงพูดภาษาไทยจริงหรือการอัดจากไมค์
